# Imagenes de coches

Coloca aqui las imagenes publicas usadas por las fichas de coches.

Nombres previstos para los coches iniciales:

- `toyota-corolla-2022.png`
- `honda-civic-2021.png`
- `ford-mustang-2023.png`
- `chevrolet-camaro-2020.png`
- `bmw-serie-3-2022.png`

Formato recomendado:

- PNG, JPG o WEBP. Ahora mismo la web usa PNG para los coches iniciales.
- Resolucion horizontal aproximada: 1200x800 px.
- Imagen limpia del exterior del coche.
- Evitar espacios, acentos y mayusculas en los nombres.
