# Car Marketplace

Full-stack web application developed with Spring Boot and React that allows users to browse, search, filter, and save vehicles as favorites.

The project includes JWT authentication, role-based authorization, a complete car management system for administrators, advanced filtering, pagination, search functionality, and a responsive user interface.

Main features:

* User registration and authentication with JWT
* Car catalog with search and filters
* Favorites management
* Admin panel for vehicle CRUD operations
* REST API built with Spring Boot
* Responsive frontend built with React
* Relational database integration
* Validation, error handling, and seed data

Technologies:

* Java
* Spring Boot
* Spring Security
* JPA / Hibernate
* MySQL / PostgreSQL
* React
* REST API
* JWT Authentication
